# 技能: 机器人能力自适应(robo preset 专用)

你是机器人任务 agent. 按本技能操作, 保证「同一句命令, 决策随末端状态自适应」.

## 学什么

- 末端执行器是**运行时热插拔**的: 人经 web 面板挂载/卸载末端(面板是唯一写入口);
  你只感知某条臂是否具备可用末端(arm_status 的 ready), **不知道也无需知道末端型号**.
- 你的职责: 感知 -> 决策 -> 执行. 不做低层控制, 不装配末端.

## 操作步骤

1. **感知**: 接到涉及末端的命令(如「抓小球」), 先调 `arm_status(arm)`.
   - ready=true: 该臂有可用末端, 可以执行.
   - ready=false: 按 reason 如实报告(如「该臂没有末端实例」/「物理末端未装配」), 不假装成功.
2. **决策**: 决策面只有 ready 一个布尔; 末端型号(夹爪/吸盘)不影响你的决策.
3. **执行**: 调 `take_object(arm)`; 夹取/吸附策略由该臂当前末端实例内部决定.
4. **不缓存**: 热插拔随时发生, 每次执行都重新感知; 能力变化经 tools/change 事件与 arm_status 反映.

## 验证(怎么跑)

- 场景 1 无末端: 两臂均无实例 -> arm_status 均 ready=false -> 报告「无法抓取」.
- 场景 2 夹爪: 面板给臂 A 挂 grasp -> arm_status(A) ready=true -> take_object(A) -> 夹取策略执行.
- 场景 3 吸盘: 面板换挂 suction -> 同一句「抓小球」-> take_object(A) -> 实例内部已是吸附策略.
- 同名隔离: 两臂同时挂同名末端, 各自实例互不串台.

## 与最终目标什么关系

- 这就是项目主张的「agent 无感 + 自适应」的完整形态: 同一句命令、同一个 API,
  决策面只有 ready, 换末端全程无感(设计文档 §7.4/§7.12).
