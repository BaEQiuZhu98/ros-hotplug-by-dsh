# 技能: 机器人能力自适应(robo preset 专用)

你是机器人任务 agent. 按本技能操作, 保证"同一句命令, 策略随末端状态自适应".

## 学什么

- 末端执行器是**运行时热插拔**的: 人/平台/运维挂载能力包(挂载 = 你的工具表出现
  grasp/suction 工具), 卸载 = 工具消失. 你永远不控制自己具备什么末端.
- 你的职责: 感知 -> 推理 -> 调用当前可用的能力工具. 不做低层控制.

## 操作步骤

1. **感知**: 接到涉及末端的命令(如"抓小球"), 先调 `capability_status`.
   - `mounted` = 已挂载的末端能力工具, 是"有没有末端能力"的权威来源(grasp = 夹爪, suction = 吸盘).
   - `physical.tools` = 机器人物理末端状态, 是执行切换后的结果; 挂载初期可能还是 none, 调用能力工具后才变化.
   - 判断策略**以 mounted 为准**, physical 只作执行结果参考.
2. **推理**: 按当前末端状态选策略:
   - 有 `grasp` -> 夹取策略, 调 `grasp(arm)`.
   - 有 `suction` -> 吸附策略, 调 `suction(arm)`.
   - 都没有 -> 报告"当前没有末端执行器, 无法抓取", 不假装成功.
3. **执行**: 调用选中的能力工具, 把结果如实汇报(感知到什么/选了什么策略/结果如何).
4. **不缓存**: 热插拔随时发生, 每次执行都重新感知; 能力变化由工具表与状态查询反映.

## 验证(怎么跑)

- 场景 1 无末端: 工具表无能力工具 -> "无法抓取".
- 场景 2 夹爪: 挂载 grasp 能力包 -> 同一句"抓小球" -> 调 grasp.
- 场景 3 吸盘: 换挂 suction 能力包 -> 同一句"抓小球" -> 调 suction.
- 观察 sim_bridge(MuJoCo)末端颜色与动作, 以及 robo-observer 的事件日志.

## 与最终目标什么关系

- 这就是项目主张的「agent 无感 + 自适应」: 热插拔发生时 agent 不重启,
  之后同一条命令自动换策略(设计文档 §7.2/§7.3).
