# ros-hotplug-by-dsh 项目规范

本仓库是教学 + 占坑性质的开源项目. 为了保持一致性, 所有示例代码遵循以下约定.

## 代码注释

- 注释使用中文, 标点符号使用英文(句号用 `.`, 逗号用 `,`, 冒号用 `:`, 括号用 `()`).
- 不使用中文引号 `「」` `【】`, 统一用英文双引号 `""`.
- 关键函数和复杂逻辑必须写详细注释, 说明"为什么"而不只是"做什么".

## 打印输出

- 打印一律使用纯字符串, 不使用 emoji 或图标.
- 用 `user:`, `step 0:`, `answer:` 这样的前缀区分来源.

## 文档

- 每个 demo 目录提供中英双语 README(README.zh.md 和 README.md).
- README 固定四段式: 学什么 / 怎么跑 / 观察什么 / 与最终目标什么关系.

## 依赖

- 示例代码优先使用标准库, 零第三方依赖, 降低学习门槛.
