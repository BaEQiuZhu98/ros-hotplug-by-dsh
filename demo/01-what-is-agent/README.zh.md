# demo/01 — Agent 是什么

## 学什么

从零建立「agent」的正确心智模型。agent 不是魔法，而是三个零件拼起来的东西：

| 零件 | 在本 demo 中 |
|---|---|
| **LLM（大模型）** | 一个「对话历史 → 下一条回复」的函数 |
| **工具（tool calling）** | `get_time`、`calc`——模型能「请求调用」的普通 Python 函数 |
| **循环（ReAct）** | 思考 → 行动 → 观察 → 再思考，直到给出最终答案 |

关键概念：
- **token**：模型读写文本的基本单位（大致是「半个词」）。
- **tool calling**：模型不直接回答，而是返回一个 `tool_calls` 请求，说「请帮我执行 `calc(expr="3*7+2")`」。
- **ReAct 循环**：模型说「我要调工具」→ 你执行 → 把结果塞回历史 → 模型再决定「继续调」还是「回答」。

## 怎么跑

```bash
# 前置：Python 3.10+，零第三方依赖（只用标准库）
export DEEPSEEK_API_KEY="sk-你的key"

# 让 agent 同时用到两个工具
python3 agent.py "现在是几点？顺便算一下 3*7+2"

# 或只触发单个工具
python3 agent.py "3*7+2 等于多少"
```

> 如果 `deepseek-chat` 不可用，设置 `export DEEPSEEK_MODEL=你的模型名`。

## 观察什么

你会看到这样的 trace（关键在「模型决定调工具 → 工具执行 → 结果回填 → 最终回答」这条链）：

```
user: 现在是几点? 顺便算一下 3*7+2

step 0: 模型决定调用 2 个工具
   tool: get_time() -> {'now': '2026-08-21T11:30:00'}
   tool: calc({'expr': '3*7+2'}) -> {'result': 23}

answer: 现在是 2026-08-21 11:30:00, 3*7+2 = 23
```

**试着改一个问题**，让它「只用一次工具」或「完全不用工具直接回答」，观察 `tool_calls` 分支如何出现/不出现。

## 与最终目标什么关系

- 你刚在 `demo/00` 里用 DSH 跑的 agent，本质就是**这套循环的工程化版本**（外加作用域、生命周期、会话管理等）。
- `demo/04` 会把「工具」换成 DSH 里注册的 plugin 工具；`demo/13` 会把这些工具变成「机器人能力」，并运行时增删——那就是「热插拔」。
- 所以：**先看懂这个 120 行的最小 agent，后面的 DSH agent 就不再是黑盒。**
