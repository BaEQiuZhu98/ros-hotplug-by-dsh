# demo/09 — 轨迹控制（trajectory control）

## 先建立直觉（零基础从这里读）

demo 08 学会了「给目标位置，反解关节角（IK）」。这一章回答两个新问题：

1. **怎么「平稳地」走过去**：光有起点终点不够，还要决定中间每一刻在哪、速度多少，这就是「**轨迹生成**」。
2. **怎么保证真的走准**：走的过程中有重力、有惯性、有摩擦，实际会跑偏，所以要用误差去修正出力，这就是「**PID 闭环控制**」。

### 三种轨迹（同一段路程，三种走法）
- **关节梯形**：每个关节的速度像梯形（先加速、再匀速、再减速），起步停止不抖。
- **笛卡尔直线**：让末端在空间里走直线（位置线性插值）。
- **SLERP**：姿态（朝向）用四元数「匀速旋转」插值，中间每一步都还是合法姿态。

### PID = 用误差来修正
- **P（比例）**：现在偏多少，就按比例出多少力纠正。
- **I（积分）**：把一直以来的误差累加起来，用来消灭「老是有个固定偏差」的稳态误差。
- **D（微分）**：看误差变化快慢，抑制超调和振荡。

### 控制回路（闭环）
```
目标轨迹 → 误差 → PID → 力矩 → 机器人(仿真) → 实际角度 → 再算误差 → ...
```
这就是「反馈」：不是一次算对就完事，而是持续边测边修正。

## 学什么

- 梯形速度轨迹生成（加速/匀速/减速三段）。
- 笛卡尔直线插值、四元数 SLERP。
- PID 三项各起什么作用，闭环仿真验证。
- 在 MuJoCo 单摆上用 PID 力矩控制跟踪轨迹，看跟踪误差。

## 怎么跑

前置：`python3` + `numpy` + `mujoco`（demo 06 已装）。

### 1. 纯数学：轨迹生成 + PID 仿真（无窗口，不需要 mujoco）
```bash
python3 trajectory.py
```
依次打印：梯形轨迹表、直线插值、SLERP、PID 阶跃跟踪（误差收敛到 0）。

### 2. 单摆 PID 轨迹跟踪（无窗口）
```bash
python3 control.py
```
打印「目标角度 vs 实际角度」对比表和最大跟踪误差。

### 3. 单摆跟踪来回摆动（交互窗口，需要图形环境）
```bash
python3 control.py --view
```

## 观察什么

1. **trajectory.py**：梯形速度「先升后平再降」；SLERP 角度匀速增长、模长恒为 1；PID 里 P 只留下固定偏差、加了 I 后误差归 0。
2. **control.py**：单摆实际角度紧贴目标轨迹，最大跟踪误差很小（重力被 PID 抵消）。
3. 试着把 `control.py` 里的 `Ki` 改成 0（只留 PD），看「保持段」是否出现固定偏差——这就是积分项的作用。
