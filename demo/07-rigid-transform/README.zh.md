# demo/07 — 刚体变换（rigid transform）

## 先建立直觉（零基础从这里读）

demo 07 只讲一件事：**怎么用数学描述「位置 + 朝向」，并在一串关节之间「接力」算出末端在哪。**

### 位置 = 3 个数
手机在房间里的位置，用「离墙、离地、离门」三个数 `[x, y, z]` 就能说清。这就是「位置」。

### 朝向还需要另外 3 个数
同一个位置，手机还能竖着 / 横着 / 面朝上摆——所以光有位置不够。**位置（3 个数）+ 朝向（3 个数）= 位姿，共 6 个自由度**，才完全描述一个刚体。

「朝向」有三种等价写法（同一个东西的不同包装，就像 `0.5 = 1/2 = 50%`）：

| 写法 | 一句话解释 | 像什么 |
|---|---|---|
| 旋转矩阵 | 3×3 数字表，直接写着「新坐标轴指向哪」 | 朝向说明书 |
| 欧拉角 | 绕 X / Y / Z 各转多少度 | 先抬头、再转头、再侧头 |
| 四元数 | 4 个数的压缩包 | 朝向的 zip 包 |

### 变换 = 转一下 + 移一下
「从讲台看的位置」要换算成「从你座位看的位置」，就是「变换」：**平移**（往前走几步）+ **旋转**（转个身）。机械臂末端在哪，就是把「转一下、移一下」从基座一路接力到末端——这叫**正向运动学（FK）**。

## 学什么

- 三种姿态表示（旋转矩阵 / 欧拉角 / 四元数）互相换算、来回转不丢信息。
- 齐次变换：把「旋转 + 平移」合成一个 4×4，一次搞定「先转再移」。
- 正向运动学（FK）：已知各关节角，用变换接力算出末端位姿，并与 MuJoCo 比对验证。

## 怎么跑

前置：`python3` + `numpy` + `mujoco`（demo 06 已装）。

### 1. 纯数学：建立直觉（无窗口，不需要 mujoco）
```bash
python3 transforms.py
```
按「位置 → 朝向 → 变换 → 打包」四层逐步打印，建议先跑这个。

### 2. 机械臂 FK 验证（无窗口）
```bash
python3 arm.py
```
打印「手工 FK 末端位置 vs MuJoCo 末端位置」对比表。

### 3. 机械臂动起来（交互窗口，需要图形环境）
```bash
python3 arm.py --view
```

## 观察什么

1. **transforms.py**：同一个旋转，用矩阵 / 四元数来回转，最大误差约 `1e-16`（说明没丢信息）。
2. **arm.py**：手工 FK 算出的末端位置 / 姿态，与 MuJoCo 内置算出的几乎完全一致（误差约 `1e-15`）。
3. **--view**：两关节臂来回摆动，末端在 X-Z 平面画弧。

## 与最终目标什么关系

- demo 08 的 FK / DH、demo 09 的轨迹控制都建立在这套「坐标系变换」上。
- demo 12 的「末端位姿 → 关节角」就是 FK 的逆（IK），用同一套齐次变换。
- 四元数是 MuJoCo / ROS2（tf）里的标准姿态表示，这里把地基打好。
