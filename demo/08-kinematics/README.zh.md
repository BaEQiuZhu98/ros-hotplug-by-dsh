# demo/08 — 运动学（kinematics）

## 先建立直觉（零基础从这里读）

demo 07 学会了正向运动学（FK）：**已知关节角，算出末端在哪**。这一章反过来。

### 正向 FK vs 逆向 IK
- **FK**：我知道每个关节转多少度，问「手够到哪了」。
- **IK**：我想让手够到某个点，问「每个关节该转多少度」。

IK 才是机器人真正天天要干的活——「把末端放到目标位置」靠的就是它。

### 为什么 IK 难
FK 是「正着算」：给角度 → 唯一一个末端位置。IK 是「反着算」：给位置 → 可能有**好几个**关节角（比如肘朝上 / 肘朝下两种姿态都够得到同一点），也可能**无解**（目标太远，超出臂展）。

### 两种解法
- **解析法**：对简单臂（如两连杆）直接用余弦定理解出公式，快、准、但只有特定结构才有闭式解。
- **数值法**：先猜一个角度，看末端离目标差多少，再用「雅可比」把误差反推成关节修正量，一步步逼近。复杂机械臂（7 轴）没闭式解，都用这套。

## 学什么

- DH 参数：用 4 个数（a/α/d/θ）描述一个关节，逐关节相乘得到 FK。
- FK：关节角 → 末端位置（demo 07 的升级，换成工业通用的 DH 写法）。
- IK 解析法：二连杆的余弦定理解。
- IK 数值法：雅可比 + 阻尼最小二乘迭代。
- 速度级逆解 + 比例控制：把「位置误差」反解成「关节速度」，让手臂追着目标跑（demo 09 轨迹控制的前奏）。

## 怎么跑

前置：`python3` + `numpy` + `mujoco`（demo 06 已装）。

### 1. 纯数学：FK / IK 反解与验证（无窗口，不需要 mujoco）
```bash
python3 kinematics.py
```
给一个目标点，用解析法（两种姿态）和数值法反解关节角，再代回 FK 验证到位。

### 2. IK 驱动到位（无窗口）
```bash
python3 ik_demo.py
```
打印「目标 → 关节角 → MuJoCo 末端」对比表，误差应接近 0。

### 3. 手臂追踪目标（交互窗口，需要图形环境）
```bash
python3 ik_demo.py --view
```
一个绿色小球（目标点）快速绕圆运动，手臂根据位置差异用比例控制追着它跑（有速度上限，会落后）。

## 观察什么

1. **kinematics.py**：同一目标有两个解析解（肘朝上 / 朝下），数值解收敛到其一；代回 FK 误差接近 0。
2. **ik_demo.py**：反解出的关节角让 MuJoCo 末端误差接近 0，证明「驱动到位」成立。
3. **不可达**：目标超出臂展时，解析法返回 `None`（detect 到无解）。
4. **追着跑**：目标跑得快时手臂跟不上、末端落后，走「追赶曲线」而不是目标圆——这就是「速度差异 → 轨迹差异」。

## 与最终目标什么关系

- 运动控制的核心：demo 09 的轨迹控制要先能「给定末端位姿 → 求关节角」。
- demo 12 的「agent 一句指令 → 机械臂动作」底层就是 IK 把目标位姿变成关节角。
- 数值雅可比是机器人控制（速度级逆解、阻抗控制）的通用工具，后面还会再用。
