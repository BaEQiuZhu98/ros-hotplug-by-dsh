# 任务 1.1：环境安装 + 最小仿真验证

状态：已完成执行（2026-11-15），待理解验证答题

## 1. 为什么做

一切建模/导航/操作都跑在 Gazebo + ROS2 上。先装好环境并验证"仿真能跑、ROS2 能通信"，避免后面建模时才发现环境问题。

## 2. 在整机项目中的作用

仿真平台基座，后续所有阶段（建模、导航、操作、故障自适应、LLM 规划）的运行环境。

## 3. 输入

- Ubuntu 24.04.5（已确认）。
- ROS2 Jazzy（已安装，`/opt/ros/jazzy`）。
- 网络、sudo 权限。
- GPU 不可用（纯 CPU 仿真）。

## 4. 输出

- Gazebo Harmonic 可启动（版本 8.x）。
- `ros_gz` 桥接包可用。
- 能从 ROS2 启动 Gazebo 世界，并确认 ROS2 与 Gazebo 之间能收发话题。

## 5. 边界与风险

- 只装环境 + 验证，不写业务代码、不建机器人模型。
- 风险 a：apt 仓库配置（需添加 OSRF 仓库）。
- 风险 b：GPU 不可用，需确认 Gazebo 软件渲染经 WSLg 弹窗。
- 风险 c：下载量大可能超时。
- 风险 d：`gz-harmonic` 不能与 gazebo11（classic）共存。

## 6. 验收方式（可复现，你执行并回报）

1. `gz sim --version` 输出 8.x。
2. `ros2 pkg list | grep -E "ros_gz|ros2_control|gz_ros2"` 能看到相关包。
3. `ros2 launch ros_gz_sim gz_sim.launch.py` 弹出 Gazebo 窗口。
4. 启动带桥接的示例后，`ros2 topic list` 能看到 gz 相关话题（如 `/model/.../cmd_vel`、`/odometry`、`/tf`）。
5. 退出后 `ps aux | grep -i "gz sim"` 无残留进程。

## 7. 详细步骤（接口在步骤中给出）

### 步骤 1：确认环境

- `source /opt/ros/jazzy/setup.bash`
- `ros2 --help`：确认 ROS2 可用。
- `lsb_release -a`：确认 Ubuntu 24.04。

### 步骤 2：确认 Gazebo 已装（预检状态：gz-harmonic 8.15.0 已装）

- `gz sim --version`：应输出 `Gazebo Sim, version 8.x`。
- 若未安装，按 Gazebo 官方文档执行：`sudo apt-get update`、`sudo apt-get install curl lsb-release gnupg`、`sudo curl https://packages.osrfoundation.org/gazebo.gpg --output /usr/share/keyrings/pkgs-osrf-archive-keyring.gpg`、写入 `/etc/apt/sources.list.d/gazebo-stable.list`、`sudo apt-get install gz-harmonic`。依据 [Gazebo Harmonic 官方安装文档](https://gazebosim.org/docs/harmonic/install_ubuntu/)。

### 步骤 3：确认 ROS2 桥接与控制包

- `ros2 pkg list | grep -E "ros_gz|ros2_control|gz_ros2"`：应包含 `ros_gz_sim`、`ros_gz_bridge`、`gz_ros2_control` 等。
- 若缺，`sudo apt-get install ros-jazzy-ros-gz ros-jazzy-ros2-control ros-jazzy-ros2-controllers ros-jazzy-gz-ros2-control`。

### 步骤 4：验证 Gazebo 本体

- 无头验证：`gz sim -s -r --iterations 20 /usr/share/gz/gz-sim8/worlds/shapes.sdf`，应正常退出（exit 0）。
- GUI 验证：`gz sim /usr/share/gz/gz-sim8/worlds/shapes.sdf`，应弹出 Gazebo 窗口（WSLg）。

### 步骤 5：验证 ROS2 与 Gazebo 桥接

- 启动带桥接的差速底盘示例：`ros2 launch ros_gz_sim_demos diff_drive.launch.py`。
- 另开终端查看话题：`ros2 topic list`，应看到 `/model/vehicle_blue/cmd_vel`、`/model/vehicle_blue/odometry`、`/tf` 等。
- 查看节点：`ros2 node list`，应看到 `/ros_gz_bridge`。

### 步骤 6：清理验证

- 退出后 `ps aux | grep -i "gz sim"` 无残留进程。

## 8. 环境注意点（agent 侧，供参考）

以下现象只在对 agent 沙箱执行时出现，你本机执行通常不会遇到；若遇上报错再排查。

1. agent 沙箱下 `$HOME=/root` 不可写，Gazebo 日志/配置会报错；agent 若需要该权限，向你单独申请，不列入你的执行步骤。
2. FastDDS 共享内存报错 `Failed to create segment ... Permission denied` 在沙箱下会出现，有 UDP 回退，不影响通信；属优化项，后续可切 `rmw_cyclonedds_cpp`。
