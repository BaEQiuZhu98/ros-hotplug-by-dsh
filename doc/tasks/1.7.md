# 任务 1.7：接触抓取可行性 spike + 软件渲染实时因子验证

状态：已规划，待执行

## 1. 为什么做

阶段 3 的核心是双臂接触夹持托盘，R1 风险（接触夹持不稳定）是整个项目的最大物理风险。1.7 用最小代价提前验证：单臂 + 简单夹爪能不能在 Gazebo 里靠接触摩擦夹起一个方块。同时记录实时因子（RTF），判断纯 CPU 软件渲染下仿真速度能否支撑后续调参迭代。这是进入阶段 2 的门禁。

## 2. 在整机项目中的作用

风险 R1、R7 的前置验证。1.7 的结论决定两条路线：

- 接触夹持可行 + RTF 可接受 → 阶段 2/3 继续在 Gazebo 做。
- 接触夹持调不出或 RTF 太低 → 触发 R1 降级路径（操作段迁 MuJoCo，导航段留 Gazebo）。

## 3. 输入

- 1.6 的整机（底盘 + 躯干 + 双臂 + 传感器 + ros2_control）。
- ur_description 的 tool0/flange（夹爪挂载点）。
- gz-sim 的接触物理（DART 引擎，1ms 步长）。
- RTF 数据源：`gz topic -e -t /world/biadapt/stats`。

## 4. 输出

- 单臂末端加一个简单两指夹爪（两个 box 手指 + prismatic joint）。
- 一个待夹方块（简单 box）spawn 在桌面。
- 验证结果：夹爪合拢能靠摩擦夹住方块、抬起不掉。
- RTF 记录值，写入 `doc/RISKS.md` 的 R1/R7 状态。

## 5. 边界与风险

- 只做单臂夹方块，不做双臂协同、不做托盘、不移动底盘（阶段 3 的事）。
- 夹爪用最简结构（两指 + prismatic），不追求真实机械夹爪。
- 风险 a：接触夹持参数（摩擦 mu、夹持力、夹爪几何）难调，可能滑落/穿模/挤飞。
- 风险 b：RTF 低（llvmpipe + 双臂 mesh + 传感器 + 接触求解叠加），仿真慢。
- 风险 c：夹爪的 prismatic joint 用 position 还是 effort 接口，直接影响夹持稳定性。

## 6. 验收方式（可复现）

1. 夹爪合拢后，方块被稳定夹住（不滑落、不穿模、不被挤飞）。
2. 抬起方块，稳定 2 秒以上不掉。
3. 记录 RTF（`gz topic -e -t /world/biadapt/stats -n 1` 的 real_time_factor），写入 RISKS.md。
4. 结论明确：Gazebo 接触夹持「可行 / 不可行」，RTF「够 / 不够」，降级路径是否触发。

## 7. 详细步骤

### 步骤 1：加简单两指夹爪

- 在 ur_description 的 `tool0` 或 `flange` 上加夹爪：
  - `gripper_base`：fixed 到 tool0。
  - 两个手指 `gripper_finger_l` / `gripper_finger_r`：box。
  - 手指用 `prismatic` joint（沿 y 轴合拢/张开），或一个 prismatic + 另一个 mimic 反向。
- 手指碰撞体设摩擦（`<gazebo reference><mu1><mu2>` 类似轮子的做法）。
- 只挂到左臂先验证（右臂阶段 3 再说）。

### 步骤 2：spawn 待夹方块

- 在 world 里加一个简单 box（比如 0.05×0.05×0.05，质量 0.1kg），放在桌面高度。
- 位置在左臂可及范围内。

### 步骤 3：配夹爪 ros2_control

- 夹爪的 prismatic joint 加 command/state interface。
- 两种驱动方式都试：
  - position 接口：合拢到略小于方块宽度的位置，靠摩擦夹持。
  - effort 接口：用 forward_command_controller 发恒力夹持。
- 观察哪种能稳定夹住（不滑落、不挤飞）。

### 步骤 4：验证接触夹持

- 左臂末端移到方块上方（先用 joint_trajectory_controller 发关节轨迹，或手动定姿态）。
- 夹爪合拢夹住方块。
- 抬起，观察方块是否稳定。

### 步骤 5：记录 RTF

- 在双臂 + 传感器 + 接触仿真的负载下：
  - `gz topic -e -t /world/biadapt/stats -n 1`，记 real_time_factor。
  - 对比：关掉传感器、关掉一条臂时的 RTF，看主要瓶颈在哪。

### 步骤 6：更新风险清单

- 结论写入 `doc/RISKS.md`：R1（接触夹持）、R7（渲染实时性）状态更新，降级路径是否触发。

## 8. 理解验证问题

1. 接触夹持（摩擦夹持）和吸附（attach/weld）的区别？为什么项目边界要求接触非吸附？
2. 夹爪 prismatic joint 用 position 接口和 effort 接口各有什么效果？接触夹持为什么对力（effort）敏感？
3. 摩擦系数 mu、夹持力、物体质量三者怎么影响夹持稳定性？mu 太小或夹持力太大会怎样？
4. RTF（实时因子）是什么？RTF < 1 会不会导致接触仿真不稳定？为什么？
5. 接触仿真里物体滑落、穿模、被挤飞的典型原因各是什么？
6. 为什么用 DART 的 1ms 步长做接触仿真？步长和接触求解稳定性什么关系？
7. spike 和完整实现的区别？为什么在阶段 3 之前先做这个最小验证？
