# 任务 1.5：加 RGB-D 相机 + 激光雷达传感器

状态：已规划，待执行

## 1. 为什么做

1.4 拼完了整机本体。现在加感知：头部 RGB-D 相机 + 激光雷达。这是阶段 2 建图导航的感知来源，也是"移动操作机器人能看见周围"的前提。

## 2. 在整机项目中的作用

感知层。RGB-D 相机提供彩色图 + 深度图 + 点云，激光雷达提供 2D LaserScan。阶段 2 的 2D 建图/导航用 `/scan`，rtabmap 点云 SLAM 用深度图/点云，两者都是后续导航与操作的输入。

## 3. 输入

- 1.4 的整机 xacro（底盘 + 躯干 + 双臂）。
- gz-sim 8 传感器用 SDF `<sensor>` 元素定义，经 URDF `<gazebo reference="link">` 嵌入（延续单源 xacro）。
- 已实测：`gpu_lidar` 在 llvmpipe 软件渲染下有数据（tb3 的 `/scan` 5 Hz）。
- 参考文件：
  - `/home/my-project/02-nv2/src/nav2_minimal_turtlebot_simulation/nav2_minimal_tb3_sim/urdf/gz_waffle.sdf.xacro`（gpu_lidar 完整配置，实测可用）。
  - `/usr/share/gz/gz-sim8/worlds/sensors_demo.sdf`（rgbd_camera 完整配置）。

## 4. 输出

- 头部 head link（fixed joint 连 torso 顶部）+ RGB-D 相机 + 激光雷达。
- 桥接后 ROS 侧话题：`/scan`（LaserScan）、`/rgbd_camera/image`（Image）、`/rgbd_camera/depth_image`（Image）、`/rgbd_camera/points`（PointCloud2）、`/rgbd_camera/camera_info`（CameraInfo）。
- RViz 可见激光扫描和相机图像/点云。

## 5. 边界与风险

- 只加传感器 + 桥接，不做 SLAM、不做导航（阶段 2）。
- 风险 a：URDF `<gazebo reference="link"><sensor>` 转 SDF 的可行性需第一步验证（sdformat 对 sensor 元素的支持）。
- 风险 b：gpu_lidar 的 frame 用 `<gz_frame_id>`，误用 gazebo classic 的 `<frame_name>` 会导致 LaserScan 的 frame_id 为空、TF 对不上。
- 风险 c：相机 + 雷达两个渲染叠加，llvmpipe CPU 负担重；需调低 update_rate（雷达 5 Hz 已实测可用，相机先试 10 Hz）。
- 风险 d：传感器坐标系朝向（相机光轴、雷达 360°）定义错误导致数据方向反。

## 6. 验收方式（可复现）

1. `ros2 topic hz /scan` 稳定输出（约 5 Hz）。
2. `ros2 topic echo /scan --once` 有 ranges 数据，frame_id 正确。
3. `ros2 topic hz /rgbd_camera/image` 和 `/rgbd_camera/points` 有数据。
4. RViz 里能看到激光扫描点，Camera 显示里能看到相机图像，PointCloud2 显示里能看到点云。
5. TF 树新增 head link 相关坐标系，无断链。

## 7. 详细步骤

### 步骤 1：验证 URDF 嵌 sensor 的转换

- 在 xacro 里给一个 link 加 `<gazebo reference="link_name">`，里面放一个最小 `<sensor type="gpu_lidar">`。
- `gz sdf -p <展开后的urdf>`，确认生成的 SDF 里该 link 下出现了 `<sensor type="gpu_lidar">`。
- 若 sensor 没转出来，说明 URDF 这条路不通，改讨论 SDF 方案。这是本任务第一个门禁。

### 步骤 2：加 head link

- 在 torso 顶部加 `head_link`（box 或 cylinder，作传感器安装座），`head_joint`（fixed）连 `torso_link`，origin 在躯干顶部。
- 建议：`head_joint` origin z = `torso_size_height/2`（相对 torso_link），head 朝 +x 方向。

### 步骤 3：加激光雷达（gpu_lidar）

- 在 head_link 上加 `<sensor type="gpu_lidar">`，参考 tb3 配置：

```
<ray><scan><horizontal> samples=360 min_angle=0 max_angle=6.28
<range> min=0.01 max=20 resolution=0.015
<update_rate>5
<topic>/scan
<gz_frame_id>head_link 或专用 scan_link
```

- 关键字段：`samples`（采样点数）、`min_angle`/`max_angle`（扫描范围，360° 用 0~6.28）、`range`（量程）、`gz_frame_id`（frame 名，不是 frame_name）。

### 步骤 4：加 RGB-D 相机（rgbd_camera）

- 在 head_link 前部加 `<sensor type="rgbd_camera">`，参考 sensors_demo.sdf：

```
<camera><horizontal_fov>1.047<image> 320x240 <clip> near=0.1 far=100
<update_rate>10
<topic>/rgbd_camera
```

- 相机光轴沿 +x（前进方向），姿态用 sensor 的 pose 或挂载 link 的朝向定。

### 步骤 5：桥接话题

- bridge 增加：

```
/scan@sensor_msgs/msg/LaserScan@gz.msgs.LaserScan
/rgbd_camera/image@sensor_msgs/msg/Image@gz.msgs.Image
/rgbd_camera/depth_image@sensor_msgs/msg/Image@gz.msgs.Image
/rgbd_camera/points@sensor_msgs/msg/PointCloud2@gz.msgs.PointCloudPacked
/rgbd_camera/camera_info@sensor_msgs/msg/CameraInfo@gz.msgs.CameraInfo
```

### 步骤 6：验证

- 按第 6 节逐条执行并回报。
