# 任务 1.2：URDF 语法入门 + 读一个开源臂 URDF

状态：待执行

## 1. 为什么做

URDF 是 ROS 描述机器人的标准格式。后续 1.3 搭底盘、1.4 挂双臂、1.5 加传感器、1.6 配控制，都要写或改 URDF。先学语法并读一个真实开源臂，建立"机器人如何被描述"的框架。

## 2. 在整机项目中的作用

建模能力基础。整机模型由多个 URDF/xacro 拼装而成；读懂开源臂的关节树，是 1.4 把两条臂挂到躯干上的前提。

## 3. 输入

- ROS2 Jazzy 环境（已确认）。
- 一个开源臂描述包：推荐 `ros-jazzy-ur-description`（UR 官方描述，含 URDF/xacro）。
- 已装工具：`check_urdf`（`/opt/ros/jazzy/bin/check_urdf`）。
- 官方资料：[URDF 教程](https://docs.ros.org/en/jazzy/Tutorials/Intermediate/URDF/URDF-Main.html)、[xacro 教程](https://docs.ros.org/en/jazzy/Tutorials/Intermediate/URDF/Using-Xacro-to-Clean-Up-a-URDF-File.html)。

## 4. 输出

- 能解释 URDF 的 `robot`、`link`、`joint`、`visual`、`collision`、`inertial` 元素及其关系。
- 能画出所读 UR 臂的关节树（根 link 到末端 link 的关节链）。
- 能列出该臂关键关节的名称与类型。
- 能说出 `visual`、`collision`、`inertial` 各自定义什么。

## 5. 边界与风险

- 只读 + 理解，不写整机、不改模型。
- 风险 a：`ur_description` 用 xacro 宏，不是直接 urdf；先理解 xacro 展开后的效果。
- 风险 b：mesh 用 `package://` 引用，容易和"关节树"混淆——mesh 是外观，关节树是运动结构。
- 风险 c：不同臂关节命名不同，记结构不记名称。

## 6. 验收方式

1. 能描述所读臂的关节树（根 link 到末端）。
2. 能准确说出 `revolute`、`prismatic`、`fixed` 三类关节在 URDF 里的含义。
3. 能指出某 link 的 `visual`、`collision`、`inertial` 分别定义什么。
4. 能解释 `check_urdf` 校验通过/失败意味着什么。

## 7. 详细步骤（接口在步骤中给出）

### 步骤 1：安装开源臂描述包

- `sudo apt install ros-jazzy-ur-description`
- 验证：`ros2 pkg prefix ur_description` 输出包路径。

### 步骤 2：定位 xacro/urdf 文件

- `ls /opt/ros/jazzy/share/ur_description/` 查看包结构。
- 进入 `urdf/` 或 `xacro/` 目录，找到 `.urdf.xacro` 文件（UR 官方通常提供 `ur.urdf.xacro` 或类似）。

### 步骤 3：展开 xacro 并校验

- 展开：`xacro <文件名>.urdf.xacro > /tmp/ur.urdf`。
- 校验：`check_urdf /tmp/ur.urdf`，看到 `Successfully Parsed XML` 之类即通过。
- 说明：`xacro` 命令由 `ros-jazzy-xacro` 提供，装 ur_description 会连带装上。

### 步骤 4：阅读并理解元素

按顺序读，边读边记：

- `robot` 根元素：name 属性。
- `link`：每个刚体。重点看 `visual`（外观几何）、`collision`（碰撞几何）、`inertial`（质量/惯量）。
- `joint`：连接两个 link。重点看 `type`（revolute/prismatic/fixed/continuous）、`parent`、`child`、`axis`、`limit`。

### 步骤 5：画关节树

- 从 `base_link`（或根 link）出发，沿 joint 的 parent→child 一路画到末端执行器 link，列出每条关节的名称与类型。

## 8. 理解验证问题

作答后把答案发我，我给出参考答案与考察点。

1. URDF 是树结构，为什么通常不能有环？如果两条臂需要互锁（闭链），URDF 怎么表达或为什么表达不了？

2. `revolute`、`prismatic`、`fixed` 三类关节的区别？`joint` 里的 `axis` 和 `limit` 分别约束什么？

3. `visual`、`collision`、`inertial` 各自作用？为什么同一个 link 要三份？

4. xacro 与 urdf 是什么关系？为什么要用 xacro？

5. `package://` 开头的 mesh 路径是什么意思？为什么不宜写绝对路径？

6. `check_urdf` 通过代表什么？它能检查出哪些问题、检不出哪些？

7. 读 UR 臂时，你能区分"关节（joint）"和"连杆（link）"吗？举一条关节链例子。
