# 任务 1.4：挂接两个开源臂，拼整机

状态：已规划，待执行

## 1. 为什么做

1.3 完成了底盘 + 躯干。现在把两条 UR 开源臂挂到躯干上，拼成完整本体。这是"从自研部件到整机拼装"的关键一步，也是阶段 3 接触抓取、阶段 5 单臂故障重构的本体基础。

## 2. 在整机项目中的作用

整机本体 = 底盘 + 躯干 + 双臂。双臂是操作的核心，且故障重构（单臂失效改用另一侧）要求双臂在 TF 树和命名上**独立、可区分**。1.4 产出双臂挂接与完整关节树，1.5 加传感器、1.6 配控制都建立在它之上。

## 3. 输入

- `ur_description` 包（已装，`/opt/ros/jazzy/share/ur_description`），含 `ur_macro.xacro` 的 `ur_robot` 宏。
- 1.3 的 `biadapt_description` 包（底盘 + 躯干已就绪）。
- `ur_robot` 宏接口（已核对，`ur_macro.xacro` 第 55 行起）：

```
params="name tf_prefix parent *origin
        joint_limits_parameters_file kinematics_parameters_file
        physical_parameters_file visual_parameters_file
        safety_limits:=false ..."
```

- `ur3` 配置目录：`/opt/ros/jazzy/share/ur_description/config/ur3/`，含 `joint_limits.yaml`、`default_kinematics.yaml`、`physical_parameters.yaml`、`visual_parameters.yaml`。

## 4. 输出

- 整机 xacro：`ur_macro.xacro` 的 `ur_robot` 宏被调用两次，双臂挂到 `torso_link` 两侧，`tf_prefix` 分别为 `left_`、`right_`。
- 完整 TF 树：`base_footprint → base_link → torso_link → left_*/right_*` 双臂关节链，无重名、无断链。
- Gazebo/RViz 可见双臂在躯干两侧，姿态合理。

## 5. 边界与风险

- 只挂臂 + 拼整机，不做 IK、不做抓取（1.7 和阶段 3）。
- 风险 a：`ur_robot` 宏参数多、四个 yaml 路径易写错。
- 风险 b：双臂不加 `tf_prefix` 会导致 link/joint 重名，`check_urdf` 报错、TF 混乱。
- 风险 c：双臂挂载位姿（高度、间距、镜像）设计不合理，两臂干涉或姿态怪异。
- 风险 d：双臂质量叠加，底盘重心上移，物理稳定性下降（Gazebo 里可能更易倾倒）。
- 风险 e：`ur_macro.xacro` 用 `$(find ur_description)` 引用，xacro 展开需要 `AMENT_PREFIX_PATH` 能找到该包。

## 6. 验收方式（可复现）

1. xacro 展开后 `check_urdf` 通过。
2. `ros2 run tf2_tools view_frames` 生成 frames.pdf，TF 树为 base_footprint → base_link → torso_link → 双臂各关节链，关节名带 `left_`/`right_` 前缀，无孤立节点。
3. Gazebo 或 RViz 里可见双臂挂在躯干两侧，姿态对称合理。
4. `ros2 topic echo /robot_description --once` 里能 grep 到 `left_shoulder_pan_joint`、`right_shoulder_pan_joint` 等前缀关节。

## 7. 详细步骤

### 步骤 1：读 `ur_robot` 宏接口

- 读 `/opt/ros/jazzy/share/ur_description/urdf/ur_macro.xacro` 的宏声明（第 55 行起），理解每个参数：`name`（模型名）、`tf_prefix`（link/joint 名前缀）、`parent`（挂载的父 link）、`*origin`（块参数，内部放 `<origin xyz rpy/>` 定义挂载位姿）、四个 yaml（关节限位/运动学/物理/视觉参数）。
- 读 `/opt/ros/jazzy/share/ur_description/urdf/ur.urdf.xacro`，看官方怎么调用 `ur_robot` 宏（传哪些参数、origin 怎么给）。

### 步骤 2：写双臂挂接

- 在整机 xacro 里 `include` 官方宏：`$(find ur_description)/urdf/ur_macro.xacro`。
- 调用两次 `ur_robot`，`tf_prefix` 分别 `left_` 和 `right_`，`parent="torso_link"`，`name` 用整机名或左右区分。
- 四个 yaml 用 `$(find ur_description)/config/ur3/xxx.yaml` 引用。
- 双臂 `origin` 对称：左臂 xyz 的 y 为正、右臂 y 为负；右臂通常需要绕 z 转 180°（`rpy="0 0 3.14159"`）做镜像，让左右臂对称。

### 步骤 3：设计挂载位姿

- 挂载点在躯干两侧上部。建议起点（可调）：左臂 `xyz="0 0.2 0.15"`、右臂 `xyz="0 -0.2 0.15"`（相对 `torso_link`），右臂加 `rpy="0 0 3.14159"`。
- 约束：两臂基座不干涉、臂不穿进躯干、左右对称、末端在可操作范围内。
- 边调边看 Gazebo/RViz 里的姿态，直到左右对称、无穿模。

### 步骤 4：展开校验

- `xacro <整机>.xacro > /tmp/whole.urdf`，`check_urdf /tmp/whole.urdf`。
- 确认无重名 link/joint，关节链完整。

### 步骤 5：spawn 验证

- `ros2 launch biadapt_description run.launch.py run_type:=gazebo`，看 Gazebo 里双臂是否挂上。
- `ros2 run tf2_tools view_frames` 看 TF 树，对照验收方式第 2 条。
- RViz 里确认双臂视觉正常、姿态合理。
