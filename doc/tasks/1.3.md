## 1. 为什么做

1.2 读懂了开源臂 URDF。现在写自己的第一个机器人模型（差速底盘 + 躯干），并让它在 Gazebo 里动起来。这是"从读模型到写模型"的转折，也是后续 1.4 挂双臂、1.5 加传感器的基座。

## 5. 边界与风险

- 只做底盘 + 躯干，不挂双臂、不加传感器（1.4/1.5）。
- 速度控制用 gz-sim 内置 DiffDrive 插件，不引入 ros2_control（1.6 引入后 DiffDrive 换 `diff_drive_controller`）。
- 风险 a：URDF 与 SDF 双份，link/joint 名必须一致，否则 TF 与仿真对不上。
- 风险 b：万向轮在 URDF（fixed）与 SDF（ball joint）表达不同，因为 URDF 没有 ball 类型；这是预期差异，不是错误。
- 风险 c：DiffDrive 的 `wheel_radius`/`wheel_separation` 必须与几何一致，否则里程计不准（1.3 只要求能转，精度 1.6 再管）。
- 风险 d：软件渲染下开 GUI 可能慢，验证物理可先用无头模式 `gz sim -s -r`，用话题检查轮子转动。

## 6. 验收方式（可复现）

1. `check_urdf` 通过（URDF 结构合法）。
2. `ros2 run tf2_tools view_frames` 生成 frames.pdf，TF 树为 base_link 下挂左轮、右轮、caster、torso，无断链、无孤立节点。
3. 启动仿真后 `ros2 topic list` 能看到 `/cmd_vel`、`/joint_states`、`/tf`。

5. 退出后 `ps aux | grep -i "gz sim"` 无残留进程。

## 7. 详细步骤

分 1.3a（建模 + TF 验证，纯 ROS）与 1.3b（spawn + 速度控制）两次提交。

### 1.3a：建模 + TF 验证（不碰 Gazebo）

步骤 1：建工作空间与 description 包

- 建工作空间 `/home/my-project/06-oneDay/biadapt_ws/`，`mkdir -p biadapt_ws/src`，在 `src` 下建包：
  `ros2 pkg create biadapt_description --build-type ament_cmake`。
- 包内建 `urdf/`、`sdf/`、`launch/` 目录。
- 最小 `CMakeLists.txt`：把 `urdf`、`sdf`、`launch` 三个目录 install 到 `share/${PROJECT_NAME}`。`package.xml` 声明依赖 `robot_state_publisher`、`xacro`、`ros_gz_sim`、`ros_gz_bridge`（exec_depend）。
- `colcon build --symlink-install` 后 `source install/setup.bash`。

步骤 2：写 URDF

link 清单（名字固定，后续 SDF 与 TF 都依赖）：

- `base_link`：底盘，box。
- `left_wheel_link`、`right_wheel_link`：驱动轮，cylinder。
- `caster_link`：万向轮，sphere。
- `torso_link`：躯干，box 或 cylinder。

joint 清单：

- `left_wheel_joint`、`right_wheel_joint`：`continuous`，`axis xyz="0 1 0"`（绕 y 轴）。
- `caster_joint`：`fixed`（URDF 无 ball 类型，caster 不驱动，fixed 即可）。
- `torso_joint`：`fixed`，把 torso_link 固定在 base_link 顶部。

每个 link 带 `visual` + `collision` + `inertial`（mass 与惯性张量用正定近似，box 惯性公式 ixx = m/12·(h²+d²) 等；1.3 只要求结构合法与能转，惯性不要求精确）。

建议尺寸（可自行调整，只要 SDF 与 URDF 一致）：base 0.5×0.4×0.12 m、驱动轮半径 0.075 m 厚 0.03 m、轮距 0.34 m（即两轮 y 向间距）、caster 半径 0.03 m、torso 0.3×0.3×0.5 m。

步骤 3：RViz 验 TF

- 写 `launch/display.launch.py`：`robot_state_publisher`（`robot_description` 参数 = URDF 内容，`use_sim_time` 先设 false）+ `joint_state_publisher_gui` + `rviz2`。
- 打开 RViz，添加 RobotModel 与 TF 显示；拖动轮子滑条，看轮子绕 y 轴转动。
- 验收：TF 树正确、无断链（对照验收方式第 1、2 条）。

### 1.3b：spawn + 速度控制

步骤 4：写 SDF（同构 + DiffDrive 插件）

- 参考 `models/vehicle/model.sdf`：`base_link`、左右轮、`caster`（ball joint）、`torso_link`，link/joint 名与 URDF 完全一致。
- 驱动轮 joint 用 `revolute`，`limit` 上下限设为很大值（如 ±1.79769e308，等价无限转动，参考范本）。
- 在 `<model>` 内加 DiffDrive 插件（字段含义见下）：

```xml
<plugin filename="gz-sim-diff-drive-system" name="gz::sim::systems::DiffDrive">
  <left_joint>left_wheel_joint</left_joint>
  <right_joint>right_wheel_joint</right_joint>
  <wheel_separation>0.34</wheel_separation>
  <wheel_radius>0.075</wheel_radius>
  <odom_publish_frequency>10</odom_publish_frequency>
</plugin>
```

字段用途：`left_joint`/`right_joint` 指定左右驱动轮关节名；`wheel_separation` 两轮间距（m）；`wheel_radius` 轮半径（m）；`odom_publish_frequency` 里程计发布频率。依据 [Gazebo Harmonic 官方教程 Moving the robot](https://github.com/gazebosim/docs/blob/c5c6608b07085e64e329616458bdc68b163c2d7a/harmonic/moving_robot.md)。

步骤 5：spawn + 桥接 + 发速度

- 启动仿真：`ros2 launch ros_gz_sim gz_sim.launch.py gz_args:="-r <你的sdf路径或世界>"`。
- 起 bridge（桥命令范本见 `diff_drive.launch.py`）：
  - `/model/<模型名>/cmd_vel@geometry_msgs/msg/Twist@gz.msgs.Twist`
  - `/world/<world名>/model/<模型名>/joint_state@sensor_msgs/msg/JointState[gz.msgs.Model`
- 起 robot_state_publisher（`use_sim_time: true`，`robot_description` = URDF）。
- 发速度：`ros2 topic pub /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.2}}"`，在 Gazebo 看轮子转、底盘动。

步骤 6：验收

- 按第 6 节逐条执行并回报结果。

## 8. 理解验证问题

1. URDF 与 SDF 各是什么？本项目 1.3 为什么用 SDF 做仿真、URDF 发 TF，而不是只用其中一个？
2. 万向轮（caster）在 URDF 用 `fixed`、SDF 用 `ball`，为什么？两处表达不一致会不会导致 TF 与仿真错位？
3. DiffDrive 插件的 `left_joint`、`right_joint`、`wheel_separation`、`wheel_radius` 各约束什么？`wheel_radius` 写错（与实际轮半径不符）会怎样？
4. 驱动轮 joint 为什么用 `continuous`（URDF）/无限限位的 `revolute`（SDF）而不是 `fixed`？`axis` 应该朝哪个方向，为什么是绕 y 轴？
5. robot_state_publisher 的 TF 数据从哪来？`/joint_states` 是从 Gazebo 桥出来还是手动发？为什么仿真里 `use_sim_time` 要设为 true？
6. 从发 `/cmd_vel` 到轮子转起来，中间经过哪几个环节（bridge → gz topic → DiffDrive 插件 → 轮子 joint）？
7. 差速底盘怎么转向？发 `linear.x=0、angular.z=0.5` 时左右轮各怎么动？
